An entry for [Laugh Track: The Crypto Trading Joke Contest](https://make.fun/bounty/u-alfasurya91-laugh-track-the-crypto-trading-joke-a454158a) on make.fun: one original one-line joke about crypto and trading life, under 200 characters.

## The joke

> I bought the dip. The dip dipped. Now my group chat calls me Exit Liquidity.

Three beats: the setup every trader knows (buying the dip), the turn (the dip keeps dipping), and the punchline at the very end — the group chat, the court of trading life, delivering its verdict.

## How to run

```sh
python3 main.py
```

The program deterministically writes the joke to `/output/entry.txt` in the grading sandbox (or `./output/entry.txt` for local runs). Python 3 standard library only — no dependencies, no network.
